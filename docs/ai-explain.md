# AI 解説（試作）

計算結果を、専門家でない人（自治体の担当者など）向けに、やさしく説明する機能です。「💬 解説」タブにあります。

## しくみ
1. 画面から `/api/explain` に、**入力条件と水車の種類だけ**を送る（計算結果は送らない）。
2. サーバーが、入力を検査し、**同じ計算コード**（`calculate`、亀の甲の判定）で計算し直して「事実（FACTS）」を作る。
3. AI（Anthropic Messages API）には、事実だけを渡し、「事実にない数値は作らない」指示で解説を書かせる。
4. 数値の根拠が常にコードに残る。AI の役割は、言葉にすること。

## 設定（環境変数）
| 名前 | 内容 |
|---|---|
| `ANTHROPIC_API_KEY` | API キー。**サーバー側のみ**（`NEXT_PUBLIC_` を付けない）。Vercel の Environment Variables に設定する |
| `ANTHROPIC_MODEL` | 使うモデル。省略時は `claude-sonnet-5-5`。費用を抑えるなら小さいモデルに替える |
| `EXPLAIN_MOCK` | `1` にすると、キー未設定でも、AI を使わない簡易な解説（ひな形）を返す（デモ用） |
| `EXPLAIN_REQUIRE_AUTH` | `0` にするとログイン確認を外せる（開発専用。本番では無効） |

- キー未設定のとき: 開発時はひな形を返す。**本番では 503**（`EXPLAIN_MOCK=1` のときだけひな形）。
- 環境変数を変えたら、Vercel では再デプロイが必要。
- API の使い方は、https://docs.claude.com を参照。

## 安全のための仕組み
- ログイン必須（未ログインは 401）。1人あたり 10 分に 10 回まで（429）。※ サーバーレスでは、回数の記録がインスタンスごと。本格運用では、外部のストア（Upstash、Supabase のテーブルなど）に置く。
- 入力は数値だけを受け付け、範囲を検査する。自由な文章は受け取らない（指示の混入を防ぐ）。
- 上流のエラーの詳細（キー、本文）は、利用者にもログにも出さない。
- 指示文で、製品の適合・性能保証・法規や補助金の断定を禁止し、「製造者や専門家に確認」を促す。
